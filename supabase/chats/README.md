# supabase/chats

Empty on purpose.

Until August 2026 the agents' conversation history lived in a second Supabase
project, one table per client (`public.chats_<Cliente>`), and this folder held
the SQL that had to be run there by hand: the `list_chat_tables()` RPC that fed
the table picker, the migration that added `turnos`, and the trigger that
un-double-encoded it.

The history now lives in the conversation-history Postgres, one schema per
client with a single `chats` table in each. Nothing has to be run there by hand
any more, because all of it moved into the code:

- the DDL for a new client (table, index, grants and the `normalize_turnos`
  trigger) is generated by `buildCreateChatsTableSql()` in
  `lib/chats-table-name.ts` and applied by `lib/chats-admin.ts` when the client
  is provisioned;
- listing the available schemas is a plain query in `lib/db/chats-history.ts`,
  so the `list_chat_tables()` RPC is no longer needed.

The deleted files are in the git history if the old project ever has to be
consulted. Migrations for Prompt Studio's own database still live in
`supabase/migrations/`.
